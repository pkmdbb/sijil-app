Log Masuk E-mel Urusetia

Rekod pengeluar & e-mel penghantar sijil rasmi

E-mel ini akan direkodkan sebagai pengeluar sijil dan dijadikan alamat penghantar (Reply-To) apabila sijil diemelkan kepada peserta.

Konfigurasi Auto-Emel Urusetia

Sambungan Penghantaran E-mel Automatik

LANGKAH 1

Klik "Log Masuk Urusetia"

Pastikan anda telah log masuk menggunakan e-mel Urusetia Pengurus.

LANGKAH 2

Buka Google Apps Script

Salin kod pendek di bawah ke script.google.com dan pilih Deploy > Web App.

LANGKAH 3

Tampal URL Webhook

Masukkan URL Web App di bawah supaya e-mel dihantar terus di latar belakang.

Klik untuk lihat kod pendek Google Apps Script 
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  MailApp.sendEmail({
    to: data.recipientEmail,
    replyTo: data.senderStaffEmail,
    subject: "Sijil Rasmi: " + data.eventName,
    htmlBody: "Tahniah " + data.recipientName + ",
Sijil anda telah diluluskan oleh Urusetia (" + data.senderStaffEmail + ")."
  });
  return ContentService.createTextOutput(JSON.stringify({status:"ok"}));
}
